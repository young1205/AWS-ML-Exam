Amazon Athena & Amazon Athena is a fully managed, serverless query engine that enables SQL-based analysis of 
structured, semi-structured, and unstructured data stored in Amazon S3. It leverages Presto, an open-source 
distributed SQL query engine, to perform fast, parallelized queries across large datasets without the need to 
provision or manage servers. Athena supports a variety of data formats including CSV, JSON, Parquet, ORC, and Avro, 
and integrates with AWS Glue Data Catalog for schema discovery, metadata management, and partitioning. 



Athena supports ANSI SQL queries, including joins, complex aggregations, and window functions, and can efficiently query large 
datasets by leveraging partitioning and columnar formats (like Parquet or ORC) to minimize data scans and reduce query costs. 
It automatically scales based on query complexity and workload, dynamically optimizing query execution plans. Athena charges 
based on the amount of data scanned per query, encouraging best practices such as data partitioning and use of columnar 
formats for cost efficiency. 



It can also be integrated with AWS services like Lambda, QuickSight, and CloudWatch 
for extended analytics and automation, making it suitable for real-time log analysis, 
ad-hoc reporting, and big data workflows. & Analytics-Technology \\

Amazon Data Firehose & Amazon Kinesis Data Firehose is a fully managed, serverless service for streaming data ingestion and 
delivery. It buffers, compresses (GZIP, Snappy), and encrypts data before delivering it to destinations like Amazon S3,
Redshift, Elasticsearch, or custom HTTP endpoints. Firehose supports real-time data transformation using AWS Lambda functions, 
allowing for on-the-fly processing. It automatically scales to handle variable throughput without user intervention, with 
fine-grained control over buffering and delivery intervals. Firehose is optimized for high-throughput, low-latency streaming 
use cases and charges based on data volume ingested, processed, and delivered. & Analytics-Technology \\

amounts of data using open-source tools like Apache Hadoop, Spark, HBase, and Hive. It allows users to quickly deploy, 
manage, and scale clusters for data analytics, machine learning, and other big data workloads. EMR integrates with other 
AWS services (e.g., S3, DynamoDB, Redshift) and provides flexibility in cluster configuration and scaling, making it 
suitable for both batch and real-time processing. It is fully managed, with automated provisioning, scaling, and maintenance, 
reducing operational complexity and cost. & Analytics-Technology \\

Amazon Glue & AWS Glue is a fully managed extract, transform, and load (ETL) service designed for preparing 
and transforming data for analytics. It automates data discovery, schema recognition, and job scheduling, 
simplifying data integration across a variety of sources (e.g., Amazon S3, RDS, Redshift). AWS Glue provides 
tools like Glue Data Catalog for metadata storage, Glue Crawlers for data discovery, and Glue Studio for visual
ETL job creation. It supports both serverless and provisioned environments, enabling scalable, cost-efficient 
data workflows. Glue can be integrated with other AWS services and is optimized for big data processing with Apache Spark. & Analytics-Technology \\

Amazon Kinesis & Amazon Kinesis is a suite of services designed to handle real-time data streaming and processing at scale. 
It allows you to collect, process, and analyze large amounts of data from various sources like IoT devices, logs, 
and social media in real time. Kinesis consists of several components:

1. **Kinesis Data Streams**: Captures and stores large streams of data, 
enabling real-time processing and analytics. Data is ingested in shards, which can be scaled based on throughput needs.

2. **Kinesis Data Firehose**: Automatically loads streaming data into other 
AWS services like Amazon S3, Redshift, or Elasticsearch for further analysis, 
without needing custom code.

3. **Kinesis Data Analytics**: Provides real-time SQL querying and analytics on 
streaming data, enabling users to process data as it arrives and generate actionable insights.

4. **Kinesis Video Streams**: Ingests, stores, and processes video streams for use cases 
like surveillance, media, and machine learning applications.

Kinesis offers scalability, low-latency processing, and integration with other AWS services, 
making it a powerful tool for managing real-time data pipelines. & Analytics-Technology \\
Amazon Kinesis Data Streams & Amazon Kinesis Data Streams is a scalable and durable service for real-time streaming data collection and 
processing. It allows you to ingest large volumes of data, such as logs, social media feeds, or telemetry data, in real time. 
The service breaks the data into shards, which are the basic units of capacity and parallelism. You can consume the data 
using Kinesis Data Streams APIs or integrate with other AWS services like Kinesis Data Analytics and Kinesis Data Firehose 
for further processing and storage. Kinesis Data Streams offers features like data retention, automatic scaling, and fault 
tolerance, making it suitable for high-throughput, low-latency streaming applications. & Analytics-Technology \\
AWS Lake Formation & AWS Lake Formation is a managed service that simplifies building and securing a data lake on
Amazon S3. It leverages AWS Glue for ETL, metadata cataloging, and schema management. Lake Formation 
provides fine-grained access control, enabling centralized permissions at the table or column level using
IAM and KMS integration. It uses the AWS Glue Data Catalog as the central metadata store. Security features 
include encryption (at rest and in transit), audit logging with CloudTrail, and cross-account data sharing. 
It integrates natively with analytics services like Athena, Redshift Spectrum, and SageMaker for scalable, 
secure data processing. & Analytics-Technology \\

Amazon EC2 & Amazon EC2 (Elastic Compute Cloud) is a scalable compute service that
provides resizable virtual machines (instances) on-demand. It supports multiple
instance types for various workloads, with customizable CPU, memory, storage, and
networking. EC2 integrates with other AWS services (e.g., S3, VPC, EBS) and supports

optimization based on usage patterns. & Compute-Technology \\

to events without provisioning or managing servers. It supports multiple languages (e.g., Python, 
Node.js, Java) and integrates with AWS services like S3, DynamoDB, and API Gateway. Lambda automatically
scales based on incoming requests and charges only for the compute time used. It enables event-driven 
architectures and offers fine-grained permissions through IAM for security. & Compute-Technology \\

Amazon Redshift & Amazon Redshift is a fully managed, petabyte-scale data warehouse service optimized for 
OLAP workloads. It uses columnar storage, data compression, and parallel query execution to 
enable high-performance analytics. Redshift employs massively parallel processing (MPP) 
to distribute queries across multiple nodes for fast query execution. It supports 
SQL-based querying with compatibility to PostgreSQL, and integrates with data lakes, 
AWS Glue, and Amazon S3. Redshift Spectrum allows direct querying of data in S3 
without loading it into the cluster. The service offers automatic scaling, 
data encryption (at rest and in transit), and fine-grained access control via IAM. 
Redshift’s workload management (WLM) helps optimize query performance, and the 
use of machine learning models enables intelligent query optimization. & Database-Technology \\
